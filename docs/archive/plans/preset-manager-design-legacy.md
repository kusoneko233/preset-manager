# 预设管理器旧设计文档归档

本文件替代根目录旧 `preset-manager-design.md`，只保留历史摘要，不再作为当前开发指导。

旧文档主要记录过以下方向：

- 独立 iframe 小窗和全屏模式。
- 左侧工作区、主预设面板、第二预设面板三栏结构。
- 分割线、窗口拖动、四角拉伸必须按“按住拖动、松开结束”的真实拖拽逻辑实现。
- AI 助手从底栏逐步演进为独立窗口和覆盖式命令入口。
- 历史、撤销、重做、快照备份系统。
- Codex 式暗色 UI 重构原则：弱边框、半透明左栏、精密列表、低噪音按钮、克制的 AI 输入框。

当前有效路线已经整合到 `docs/roadmap.md`。后续开发以 `docs/roadmap.md` 为准。
