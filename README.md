# Preset Manager

酒馆预设管理器，用来在独立窗口中查看、整理、编辑、对比和备份 SillyTavern 预设里的 prompt 条目。

## 当前状态

最新已归档标签：`v0.5.1`

当前工作区暂无已规划但未归档的版本内容。

核心能力：
- 独立小窗和全屏模式，支持窗口拖动、四角缩放和位置保存。
- Codex 方向的暗色/亮色 UI，支持预设条目比例、字体比例和内容预览行数设置。
- 主预设面板和第二预设面板，可展开对照、复制和迁移条目。
- 预设条目查看、收藏、插入、编辑、删除、启用/禁用、拖拽排序。
- 操作历史、撤销/重做、指定历史恢复、手动/自动快照管理。
- AI 助手覆盖式输入框和展开面板基础能力。
- UI 批注模式，可直接在插件界面上画线、框选、标号、文字批注和标尺测量。

## 版本号规则

正式发布前，本项目统一使用 `v0.x.x` 预发布版本；开发期同一阶段内的功能补充、Bug 修复、UI 细节和文档维护优先使用 PATCH 位归档，避免过早消耗 MINOR；等功能和 UI 稳定后，正式版再从 `v1.0.0` 开始。

- `v0.x.x`：开发期和预发布版本，可以继续较大幅度调整 UI、数据结构和交互。
- `v0.MINOR.0`：开发期阶段入口或较大功能组，例如编辑器、备份系统、AI 独立窗口、批注模式。
- `v0.MINOR.PATCH`：同一阶段内的功能补充、Bug 修复、UI 细节、文档和不破坏行为的小改动。
- `v1.0.0`：第一个正式稳定版，功能面和安装方式基本确定后再使用。
- `v2.0.0+`：正式版之后的破坏兼容性结构变化。

## 仓库维护流程

日常开发使用：
```bash
pnpm watch
```

每次准备存档版本时执行：
```bash
pnpm build
git diff --check
git status --short
git add <changed-files>
git commit -m "<type>: <summary>"
git tag -a vX.Y.Z -m "vX.Y.Z <release title>" -m "<release notes>"
git push origin main vX.Y.Z
```

建议：
- `src/preset-manager` 和 `dist/preset-manager` 都提交。
- `src` 是可维护源码。
- `dist` 是酒馆实际可加载的构建产物，方便直接安装和回档。
- 每个 tag 都写清楚新增、修复和构建情况。
- GitHub Release 可以基于 tag 发布，Release notes 复制对应版本记录即可。
