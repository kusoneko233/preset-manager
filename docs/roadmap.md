# 预设管理器路线图

本文档是当前唯一的功能路线和 UI 改造任务账本。旧方案文档只作为历史参考，归档在 `docs/archive/`。

## 工作规则

- 每次开始任务前先检查本文档。
- 涉及酒馆助手开发时，Codex 必须手动读取 `AGENTS.md` 引用的 `.cursor/rules/*.mdc` 规则文件。
- 新需求先归类为“当前节点 / 下个节点 / 暂缓”，再改代码。
- 每完成一个稳定节点，更新本文档、构建验证、提交 git。
- 正式发布前版本号统一使用 `v0.x.x`；功能和 UI 稳定后再从 `v1.0.0` 开始。
- 新增项目 Markdown 默认使用中文。

## 当前设计基准

- 小窗默认尺寸：`1375x875`，用于对照 Codex 截图比例。
- Codex 贴图参考尺寸记录：整体窗口约 `1375x875`；左侧栏约 `320px`；右侧主区约 `1055px`；顶栏约 `52px`；底部命令输入框约 `800px` 宽、`112-124px` 高。
- 这些基准已固化在 `src/preset-manager/designMetrics.ts`，后续 UI 调整优先改设计标尺，不在组件里散落魔法数字。
- UI 方向：接近 Codex 的精密工具界面，强调简洁、干净、低噪音、半透明侧栏、弱边框、明确层级。
- 暗色模式不使用单一纯黑，使用多层黑灰建立空间。
- 预设条目走高级列表感，不走厚重卡片堆叠。
- AI 助手是内嵌命令入口，不是横跨全屏的外置聊天底栏。
