# Preset Manager

酒馆预设管理器，用来在独立窗口中查看、整理、编辑和备份 SillyTavern 预设里的 prompt 条目。

## 当前状态

当前推荐版本：`v1.2.0`

核心能力：

- 独立窗口和全屏模式，支持窗口拖动、四角缩放和位置保存。
- Codex 风格暗色/亮色 UI，支持预设条目比例、字体比例和内容预览行数设置。
- 主预设面板和第二预设面板，可展开对照。
- 预设条目查看、收藏、插入、编辑、删除、启用/禁用。
- 操作历史、撤销/重做、手动/自动快照基础能力。
- AI 助手底栏基础能力。

## 版本号规则

本项目按语义化版本思路维护：

- `MAJOR`：破坏兼容性的结构变化，例如数据结构不兼容、安装方式大改。
- `MINOR`：新增功能，例如新增编辑器、备份系统、AI 独立窗口。
- `PATCH`：Bug 修复、UI 细节、文档和不破坏行为的小改动。

示例：

- `v1.2.1`：修复历史面板显示问题。
- `v1.3.0`：新增完整历史恢复功能。
- `v2.0.0`：更换数据存储结构且旧版本无法直接兼容。

## 仓库维护流程

每完成一项明确更新后执行：

```bash
pnpm build
git diff --check
git status --short
git add <changed-files>
git commit -m "<type>: <summary>"
git tag -a vX.Y.Z -m "vX.Y.Z <release title>" -m "<release notes>"
git push origin main vX.Y.Z
```

建议：

- `src/preset-manager` 和 `dist/preset-manager` 都提交。
- `src` 是可维护源码。
- `dist` 是酒馆实际可加载的构建产物，方便直接安装和回档。
- 每个 tag 都写清楚新增、修复和构建情况。
- GitHub Release 可以基于 tag 发布，Release notes 复制对应版本记录即可。
