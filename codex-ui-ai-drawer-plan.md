# Codex UI AI Drawer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rework the preset manager into a cleaner Codex-like workspace, with the AI assistant contained inside the preset workspace as a lightweight drawer or input capsule.

**Architecture:** Keep the existing Vue component structure and Pinia stores. Change layout behavior in `App.vue`, visual hierarchy in the main components, and AI presentation in `AiAssistant.vue` without changing preset data structures.

**Tech Stack:** Vue 3 single-file components, Pinia stores, existing Font Awesome icons, `pnpm build`, SillyTavern helper live loading through `http://localhost:5500/dist/preset-manager/index.js`.

## Execution Order

1. Visual foundation first, because every later component inherits the theme tokens.
2. Preset workspace and prompt rows second, because this is the main daily-use surface.
3. AI drawer third, because it depends on final workspace spacing.
4. Sidebar/title/split polish fourth, because these are cross-cutting refinements.
5. Build, visual verification, changelog, commit, tag last.
